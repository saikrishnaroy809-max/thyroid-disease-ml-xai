# Thyroid Disease Prediction Frontend

React + Vite frontend for the Thyroid Disease Prediction project.

## Features

- Thyroid disease prediction
- Probability display
- SHAP explainability
- Counterfactual explanations using DiCE
- Mobile-friendly responsive interface

## Backend API

The frontend connects to:

https://thyroid-disease-ml-xai.onrender.com

## Technologies

- React
- Vite
- Axios
- Recharts
- CSS

## Disclaimer

This is an academic decision-support project.

The model output is not a medical diagnosis. Clinical interpretation is required.
